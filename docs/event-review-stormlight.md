# Stormlight event review

**Reviewed by Eric, 2026-11-10** (books 1–5 from memory; books 6–7 leaned on the wiki checks).

Events catch spoilers written in plain words: a **subject** (usually a character) within 20 words of a **cue** word, e.g. "Teft" near "died".
An event is blurred for readers **on its book or any earlier book** (unlike terms, the current book counts too).

How to review: for each event, check (1) it really happens in that book, (2) the cues are how fans would phrase it, (3) nothing obvious is missing.
When unsure, the later book is the safe choice: it blurs for more readers.

Checked so far: a test with 11 spoiler-style sentences (10 caught; the miss "Dalinar became a god" was fixed by adding the cue) and 5 harmless ones (none blurred).
False blurs on 13 MB of ordinary text (novels, plays, web chat): 0 on normal pages, 4 of 44,453 snippets (0.009%) on Stormlight pages, all "Honor" + "death" in Shakespeare.
Not yet measured: false blurs in real Stormlight fan discussion. That needs testing on Reddit.

Death words used below ("death words"): die, dies, died, dying, dead, death, killed, kills, killing, murder*, slain, executed.
`*` = any ending. *context* = only on pages about Stormlight.

## Known gaps

- Events from the last book stay blurred even after finishing it, until the popup gets a "finished the series" option.
- Novellas have few events (Edgedancer 1, Dawnshard 1).
- The catch-all "Main character deaths" blurs any main character + death word until book 7. It is the most likely source of false blurs; tune it first if Reddit feels over-blurred.
