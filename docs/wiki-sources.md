# Wiki sources for checking terms and events

Standard: check every term and event against the series' **fandom.com wiki** (book plot-summary pages
first, then character pages), through the MediaWiki API (`/api.php?action=query&prop=revisions...`).
Fall back to Wikipedia's book plot summaries when the fandom wiki is thin.
Anything that can't be confirmed goes in the **later** book (safe direction) with confidence `low`.

| Series | Wiki | Quality (Nov 2026) |
|---|---|---|
| Stormlight, Mistborn | coppermind.net (not fandom; the official fan wiki) | Excellent. Every claim has a book/chapter reference. |
| The Empyrean | the-empyrean-series.fandom.com | Good: detailed plot summaries on each book page (Fourth_Wing, Iron_Flame, Onyx_Storm). Character pages patchy. |
| Realm of the Elderlings | robinhobbelderlings.fandom.com | Good: character pages have per-book sections and status. Plus Wikipedia plot summaries. |
| ACOTAR | acourtofthornsandroses.fandom.com | Good for books 1–5. Book 6 (Oct 2026) has only the blurb so far: recheck as it fills in. |
| Dungeon Crawler Carl | dungeon-crawler-carl.fandom.com | Good: per-book sections with spoiler tags. |
| Empire of the Vampire | empire-of-the-vampire.fandom.com | Thin: book pages ~400 characters, many character stubs. Mostly book 1. Events beyond book 1 rely on the catch-all. |
